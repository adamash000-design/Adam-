# מילים להכתבה

אתר תרגול להכתבות באנגלית: משחקים, דפי תרגול להדפסה ושיתוף, והכתבות מוכנות.

האתר הוא קובץ אחד, `index.html`, בלי שרת ובלי התקנה.

## הוספת הכתבה חדשה
ב-`index.html` מחפשים `var LIBRARY = [` ומוסיפים בראש הרשימה הכתבה חדשה, כל מילה כזוג `en` ו-`he`. ההכתבה הכי חדשה נטענת לבד לכל מי שפותח את האתר.

## הערה
קריאת תמונה של מחברת עובדת רק כשהדף רץ בתוך Claude. מחוץ לו האפשרות מוסתרת, וכל השאר עובד.
